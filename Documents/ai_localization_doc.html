                    POST
                    /api/v1/Translation/BatchTranslate
                

                
Creates a Google Gemini batch translation job for multiple prompts and target cultures. Keywords are stored with the batch for easier filtering. Request count and total translation count are limited by backend configuration.

                    POST
                    /api/v1/Translation/PendingBatches
                

                                
Lists translation batches across all statuses when no status filter is provided. Use keywords and optional status codes to narrow the results. Status values: 0 = InProgress, 1 = Completed, 2 = Failed. Requested page size is capped by backend configuration.

                    GET
                    /api/v1/Translation/BatchStatusList
                

                
Returns the list of translation batch statuses so clients can populate status filters without hard-coding enum values. Current values are InProgress, Completed, and Failed.


                
Request

                

                    

                        

                        
                        
                    

                    

                

                

            


            
            

                

                    GET
                    /api/v1/Translation/BatchStatus
                

                
Returns the current status for a batch. By default it refreshes the status from Google before returning; set RefreshFromProvider to false if you only want the persisted value.


                
cURL & Execution

                

                    

                        

                        
                        
                    

                    

                

                

            


            
            

                

                    GET
                    /api/v1/Translation/BatchOutput
                

                
Downloads and groups the completed output of a translation batch by request key and target culture. If the batch is not completed yet, the response returns the current batch state with an empty output list.
